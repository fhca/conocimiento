Toda función $f:A\longrightarrow A$ aplicada sobre un valor y que es susceptible de componerse consigo misma una y otra vez, es decir $f^2(x)=f(f(x))$, $f^3(x)=f(f(f(x)))$, se le llama mapeo. Para ello, se suele tomar $X\subset A$, de manera que $f(x)\in X$, para toda $x\in X$.
Se usa para representar un sistema dinámico, donde $f^1(x_0)$, $f^2(x_0)$, $f^3(x_0)$, etc. representan las *iteraciones* o *estados del sistema* y al conjunto de estos valores se le llama la [[órbita]] de $f$ desde el punto $x_0$. [[@Devaney]]
Se utilizarán mapeos para representar sistemas complejos y estructuras matemáticas asociadas.
