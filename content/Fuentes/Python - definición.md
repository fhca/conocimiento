#### Python is a programming language that lets you work more quickly and integrate your systems more effectively.

You can learn to use Python and see almost immediate gains in productivity and lower maintenance costs. [Learn more about Python](https://www.python.org/about).

---
Python es un lenguaje de programación multi-paradigma, incluyendo los paradigmas
- Procedural
- Orientada a Objetos
- Funcional
los cuales se pueden usar de manera indistinta. Creado por Guido Van Rossum. Como ventajas sobre otros lenguajes es que es muy rápido de implementar código y probarlo, además de que tiene bibliotecas de muy buena velocidad para análisis de datos, ML, etc.
